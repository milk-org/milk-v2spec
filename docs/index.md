# MILK-spec

Specifications and design board for CACAOv2.

Relevant repositories:

- [milk-spec](https://github.com/milk-org/milk-spec) -- this.
- [milk](https://github.com/milk-org/milk) -- main repo.
- [cacao](https://github.com/cacao-org/cacao) -- as an embed (not a submodule) in milk.
- [ImageStreamIO](https://github.com/milk-org/ImageStreamIO) -- as a submodule in milk.

Other info:

- [camstack](https://github.com/scexao-org/camstack) -- the command-control server for cameras on SCExAO
- [hardwaresecrets](https://github.com/scexao-org/hardwaresecrets) -- drivers & hardware linkage to ImageStreamIO.
- **XWCTk** [arxiv](https://arxiv.org/html/2608.10156v1) -- MagAO-X application layer for instrument control and CACAO RTC orchestration. May be lots to pick up there.
